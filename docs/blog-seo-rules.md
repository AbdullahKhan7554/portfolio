# Blog SEO rules

1. Keep the slug and publish date. Set an updated/dateModified date to today only if the blog page already reads that field; otherwise tell me.
2. SEO title: max 60 characters, focus keyword near the start, catchy and honest (number or year if it fits). Post title (H1) must contain the focus keyword.
3. Meta description: 140-160 characters, focus keyword included naturally, ends with a reason to click.
4. Intent: decide if the keyword is informational or buying intent and write exactly for that. Answer/purpose in the first 2-3 sentences. Focus keyword in the first 100 words.
5. Length: minimum 1000 words of real, useful content for Pakistani business owners (PKR, Lahore/Pakistan context where relevant). Simple clear English, short paragraphs.
6. Headings: one H1 only (the title). Main sections H2, sub-points H3, never skip levels. Keyword or close variations in 2-3 H2s naturally.
7. Table of contents at the top if the blog template supports it; if not, tell me and don't build one.
8. FAQ at the end: 4-5 real questions people ask about the keyword, direct answers of 40-60 words each, in the FAQ data format the blog already uses so FAQPage schema keeps working.
9. Keyword density natural, about 0.75-1%. No stuffing.
10. Cover image alt text contains the focus keyword.
11. Links: at least 2 internal links (one to the most relevant /services/* page, one to a related blog post on the site) and 1 external link to an official/authoritative source.
12. End with a short CTA linking to /contact or /free-audit.
13. Don't invent statistics, client names or results. Keep price figures already in the post; if a number is needed and missing, add a clear TODO instead of guessing.
14. Run lint and build.
15. Reply short: for each post give title, meta description, word count and any TODOs.
