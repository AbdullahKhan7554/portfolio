# Business descriptions — Avenix Studio

Three lengths, written to be pasted as-is. Most directories cap the description field
somewhere between 150 and 750 characters, so one of these will fit almost anywhere.

**Use them verbatim.** Rewriting slightly for each directory is how inconsistency
creeps in, and consistency across sources is the entire point of citation building.

Every claim here traces to `src/config/client.config.js`, `src/data/services.js` or
`src/data/servicePages.js`. There are deliberately **no client counts, no project
counts, no years-of-experience claims and no metrics** — none of those exist in the
codebase, and a directory profile is a bad place to start inventing them.

---

## SHORT — 147 characters

For fields capped at ~150, and for social bios.

```
Avenix Studio is a software development and AI automation company in Lahore, Pakistan. Custom software, mobile apps and SEO for growing businesses.
```

---

## MEDIUM — 297 characters

The most commonly useful length. Fits most directory description fields.

```
Avenix Studio is a software development and AI automation company based in Lahore, Pakistan, founded in 2023. We build custom software and web applications, cross-platform mobile apps, AI automation and chatbots, and provide SEO — for clients across Pakistan and internationally. You own the code.
```

## LONG — 736 characters

For agency directories and anywhere with a generous description field.

```
Avenix Studio is a software development and AI automation company based in Lahore, Pakistan, founded in 2023. We work across four core areas: custom software and web application development on Next.js, React and Node.js; cross-platform mobile app development in React Native and Flutter; AI automation, AI agents and chatbots wired into the tools a business already runs; and SEO covering technical, on-page, local and answer-engine work.

We take a project from scope through architecture, build, testing and launch, with a fixed written quote agreed before any work begins. Clients own their source code, content and accounts outright — nothing is locked to a proprietary platform. We serve businesses in Pakistan and internationally.
```

## Why these say "Lahore, Pakistan" and not "Lahore, Punjab, Pakistan"

Deliberate, and not an inconsistency. There are two different things here:

- **The structured address field** on a directory form is parsed and cross-referenced.
  It always takes the canonical form: `Lahore, Punjab, Pakistan`. Never vary it.
- **Description prose** is read by humans. "based in Lahore, Pakistan" is how a person
  writes a sentence; inserting the province mid-sentence reads like a form field and
  helps nothing.

Search engines match the address field against your other citations. They do not
require your marketing copy to recite your province. So: canonical form in the address
field, natural form in the prose — and do not "fix" one to match the other.

## Rules if you have to edit these

If a platform forces a change, keep these fixed:

1. **"Avenix Studio"** — never "Avenix Studios", never with a keyword suffix appended.
2. **"Lahore, Pakistan"** — city and country together, always.
3. **"founded in 2023"** — the only date claim. Do not round it to "since 2020" or
   add "over X years of experience".
4. **The four services** — software development, mobile apps, AI automation, SEO.
   Named in that order for consistency across listings.
5. **No metrics.** No "100+ projects", no "50+ clients", no "99% satisfaction". If
   a directory has a mandatory field asking for project count, enter the real number
   or leave it blank. An inflated figure on a public profile is a liability, and it
   contradicts the rest of the site, which deliberately states none.

## Keywords these descriptions are built around

Not stuffed — each appears once, in a sentence that would exist anyway. They match
the four service pages so the listings and the site reinforce each other:

- software development company Lahore / Pakistan
- AI automation services
- mobile app development Pakistan
- SEO services Pakistan
- custom software development
- web application development

If a directory offers a separate keywords or tags field, use these there rather than
forcing more of them into the description.
