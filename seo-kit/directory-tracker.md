Before submitting anywhere, have `nap-canonical.md` open. Paste; do not retype.

> **Google Business Profile is still the first thing you do**, regardless of the row
> order below. It is the anchor citation — every other listing gets cross-referenced
> against it, so it must exist and be verified before the rest are worth submitting.
> It sits in Section 3 only because its URL was not part of this verification pass,
> not because it dropped in priority. See `gbp-optimization.md`.

## Status column — what the values mean

| Value | Meaning |
|---|---|
| `confirmed — ready to submit` | URL confirmed by live search. Go straight there and submit. |
| `existing — update to match NAP` | Profile already exists (URL from `client.config.js`). Needs its NAP and description brought in line — not a new signup. |
| `[verify]` | Platform worth checking, URL **not** confirmed. Search for it, confirm it is live and genuinely free, then fill the cell in yourself. |

**Only a URL confirmed by live search is marked `confirmed`.** Everything else stays
`[verify]`, including platforms whose URLs look obvious. A plausible-looking URL that
has quietly moved or died is worse than an honest gap, because you only find out after
you have built a listing on it.

**No domain authority, traffic or "DA" figures appear in this file.** Those are
third-party estimates that change monthly. Ordering below is by verification status and
platform type, not by a metric.

## Rules while submitting

1. **Paste, never retype.** Every manual retype is a chance to introduce
   "Avenix Studios" or "+92 3026234429" and quietly break the consistency this kit exists to protect.
2. **One sitting per section.** Muscle memory reduces errors; stopping halfway through a
   section and returning a week later is when variants creep in.
3. **Use the same email for every account** — see the email decision in
   `nap-canonical.md`. Sort that out *before* you start.
4. **Record the profile URL** in the Live column as you go. You will need them for
   auditing, and for the `sameAs` list if you later extend the site's schema.
5. **Decline paid upgrades on the first pass.** Judge whether any is worth paying for
   only after you can see which listings send real traffic.
6. **Re-audit every six months.** Directories mangle data, get sold, and go stale. Put
   a recurring reminder in the calendar now.
